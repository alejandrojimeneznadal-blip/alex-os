Configuración

Cuenta

Cómo te llama el asistente y qué sabe de ti. El contexto va al principio de su prompt en cada mensaje: dos o tres frases (a qué te dedicas, qué persigues, qué tono prefieres).

Tema

Se aplica al instante y se recuerda en este dispositivo.

Conectar con otras IAs

Genera un token para usar este panel desde Claude Code, Claude Desktop u otra IA compatible con MCP: podrá consultar tu score, tus tareas y tus proyectos, y registrar lo que le cuentes. Cada token da acceso solo a tu cuenta, y puedes revocarlo cuando quieras.

Airwallex sin conectar

API key con scopes de Balances, Financial transactions e Issuing (opcional, para el nombre del comercio). Recuerda el whitelist de IP en Airwallex: al deployar, la IP del servidor.

Mercury sin conectar

Token de API read-only (Settings → API en Mercury). Sin caducidad.

Sincronización

Sync bancario

El primer sync trae 365 días de movimientos directamente de los bancos; los siguientes solapan 7 días y deduplican por id externo. Las credenciales viven solo en la base de datos de esta instancia.

Memoria del chat

Hechos durables que el chat tiene delante en cada conversación (decisiones, preferencias, contexto). Él la mantiene solo — «recuerda que…» — y aquí puedes corregir, añadir o borrar. Toca una entrada para editarla.

Hábitos y score

Los hábitos se editan en el panel (⋯ en «Hábitos de hoy»: añadir, quitar, reordenar y cambiar puntos) o por el chat: «añade un hábito de lectura con 5 puntos»…
